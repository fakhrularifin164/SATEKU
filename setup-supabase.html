PROJECT SUPABASE DIPERLUKAN

Hubungkan kasir & dapur.

Kode database, login, realtime, dan pembatasan akses sudah disertakan. Project Supabase belum dibuat untuk toko ini; belum ada koneksi database atau akun staf aktif.

Tidak ada password bawaan. Jangan kirim password database, service_role key, atau secret key melalui chat atau menaruhnya di kode frontend.
  1. Buat project milik Anda di Supabase Dashboard. Simpan password database secara pribadi.
  2. Unduh ZIP SATEKU, buka folder supabase, lalu jalankan 001_schema.sql sekali di SQL Editor. Script ini membuat tabel, fungsi transaksi, RLS, dan publikasi Realtime.
  3. Jalankan 002_catalog.sql untuk mengisi 17 menu. Harga yang disertakan adalah contoh; sesuaikan sebelum menerima pesanan nyata.
  4. Di Authentication → Users, buat akun email/password terpisah untuk kasir dan dapur. Gunakan password kuat dan sampaikan kepada staf melalui saluran pribadi.
  5. Buka 003_staff_example.sql. Ganti placeholder email dengan email staf Anda, lalu jalankan perintah role yang sesuai. Login saja tidak otomatis memberikan hak akses.
  6. Di pengaturan hosting, tambahkan SUPABASE_URL berisi Project URL dan SUPABASE_PUBLISHABLE_KEY berisi publishable/anon key. Kunci ini memang untuk frontend. Jangan gunakan service_role atau sb_secret_.
  7. Deploy ulang konfigurasi hosting. Buka kasir.html dan dapur.html, lalu login menggunakan akun dengan role yang sesuai.
  8. Coba pesanan uji dari perangkat pelanggan. Pastikan masuk ke kasir. Kasir baru mengonfirmasi pembayaran setelah dana diterima; dapur kemudian menerima pesanan. Coba status Memasak → Siap, lalu kasir menyelesaikan pesanan.

Hak akses yang disiapkan

Pelanggan: dapat membuat pesanan dan melihat status pesanan dengan link pelacakan rahasia; tidak bisa melihat seluruh pesanan toko.

Kasir: dapat melihat pesanan, nominal, kontak, mengonfirmasi penerimaan uang, membatalkan antrean yang belum dimasak, dan menyelesaikan pesanan siap.

Dapur: hanya melihat tiket makanan dari pesanan terverifikasi. Tidak mendapat nama, WhatsApp, atau alamat pelanggan. Bisa mengubah status menjadi dimasak dan siap.

Admin: dapat membuka kedua panel dan memperbarui katalog lewat Supabase Table Editor. Panel admin demo lokal bukan sumber harga saat database terhubung.

Status dan notifikasi

Dashboard staf memakai Supabase Realtime dengan pemeriksaan cadangan setiap 15 detik. Bunyi harus diaktifkan dengan tombol pada dashboard dan bergantung pada izin serta kemampuan browser. Pelacakan pelanggan diperiksa otomatis setiap 8 detik melalui fungsi database dengan token pesanan.

Pernyataan pelanggan sudah bayar hanya memberi tanda untuk kasir, tidak mengubah status menjadi lunas. Pembatalan tidak otomatis mengembalikan dana. Nomor pesanan bukan nomor antrean printer fisik.
